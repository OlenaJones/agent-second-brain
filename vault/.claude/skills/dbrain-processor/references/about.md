## Notes Processing Preferences

### Language and Style

* English (professional), Russian acceptable for personal notes
* Prefer **precise terminology**, no hype or vague claims
* Bullet points, short paragraphs, explicit outcomes

### Structure

Preferred format:

```
Context → Insight → Implication → Next Action
```

No notes without a **Next Action** unless explicitly marked as reference.

### Prioritization

* **Urgent (p1–p2):**
  Time-bound tasks that block planned work, launches, or income
* **Strategic (p3–p4):**
  System building, automation, learning that supports long-term stability
