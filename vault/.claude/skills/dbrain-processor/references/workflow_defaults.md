# Workflow Defaults

Ideas:
- Do not develop automatically.
- Ask what to do with the idea first.

Knowledge inputs:
- Produce two layers:
  1) Structured reference
  2) Practical actions

Planning:
- Always check against:
  - 3-year vision
  - Yearly focus
  - Current capacity

Artifacts:
- Do NOT create files, tables, or SOPs unless explicitly requested.
- Always propose changes before applying them.
